# yolov8-object-detector-gui
A real-time object detection desktop application with interactive GUI built using YOLOv8, OpenCV, and Tkinter. Features include live webcam/video processing, adjustable confidence thresholds, FPS monitoring, and screenshot capabilities.
# YOLOv8 Real-Time Object Detector with GUI

![Demo](screenshots/demo.png)

A powerful, user-friendly desktop application for real-time object detection using YOLOv8. Built with Python, Tkinter, and OpenCV, this application provides an intuitive interface for object detection from various sources including webcams, video files, and images.

## ✨ Features

- **Multiple Input Sources**: Webcam, video files (MP4, AVI, MOV), and images
- **Real-time Detection**: Live object detection with adjustable confidence thresholds
- **Interactive GUI**: Modern dark-themed interface with intuitive controls
- **FPS Monitoring**: Real-time performance metrics
- **Detection Logging**: Live list of detected objects with counts
- **Screenshot Capture**: Save detection results with one click
- **Model Flexibility**: Support for any YOLOv8 model (.pt files)
- **Customizable Display**: Toggle labels, confidence scores, and FPS overlay
- **Multi-platform**: Works on Windows, Linux, and macOS
